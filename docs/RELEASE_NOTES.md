# Release Notes

## v1.0.0 - AI Content Repurposer

Primeira versao funcional do projeto.

### Inclui

- Script CLI em Python para gerar resumo, posts e titulos a partir de texto longo.
- Dashboard web para revisao e aprovacao das pecas geradas.
- README completo com instrucoes de uso e aprendizado.

### Branches do workflow

- `main`: versao estavel
- `feature/cli-repurposer`: desenvolvimento do script
- `feature/dashboard`: desenvolvimento da interface
- `staging`: integracao antes de ir para main
